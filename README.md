# Greenfield Matriculation School — Web Portfolio Demo

> "Growing Minds. Building Futures."

A modern, trustworthy, family-oriented, production-quality website prototype built for **Greenfield Matriculation School**, a fictional day school in Saravanampatti, Coimbatore, Tamil Nadu, India.

---

## 🌟 Highlights & Features

- **Brand & Aesthetics**: Deep forest green (`#124032`), fresh green (`#2E7D5E`), soft golden yellow (`#EAB308`), warm cream (`#FAF9F5`), and dark charcoal (`#1F2937`) styling.
- **Typography**: `Poppins` headings + `Inter` body text system.
- **Navigation**: Sticky navbar with emblem logo (Leaf, Book, Sun SVG), active route indicator, mobile drawer, and top announcement utility bar.
- **Complete Multi-Page Architecture**:
  - ` / ` — **Home**: 12 complete sections including Hero, Trust Bar, Principal Welcome, Why Greenfield, Academic Stages, Campus Preview, Student Life, Achievements, Parent Testimonials, Admissions CTA, News Updates, and Final Visit CTA.
  - ` /about ` — **About Us**: Our Story (since 2004), Vision & Mission, 6 Core Values, Principal's Message.
  - ` /academics ` — **Academics**: Pre-Primary to Grade 12 stages, Senior Secondary Science & Commerce streams, Assessment methodology.
  - ` /admissions ` — **Admissions**: 5-step application process, Required document list, Age guidelines table, FAQ accordion, and interactive Enquiry Form.
  - ` /campus ` — **Campus & Facilities**: Category filters (Academic, Tech, Sports, Culture, Safety), GPS-tracked transport, and 24/7 CCTV details.
  - ` /student-life ` — **Student Life**: Clubs grid, 4-House System (*Agni*, *Aakash*, *Prithvi*, *Jal*), student leadership.
  - ` /achievements ` — **Achievements**: Milestones in board exams, district sports, and regional science fairs.
  - ` /gallery ` — **Photo Gallery**: Filterable category grid with **Interactive Lightbox Modal** supporting keyboard navigation (`Left`, `Right`, `Escape`).
  - ` /contact ` — **Contact Us**: Address, Phone, Email, Office Hours, Interactive Map visual placeholder, and Contact Form.
  - ` * ` — **Custom 404 Page**: Friendly error page with navigation buttons.
- **Interactive Global Modal**: Global Quick Admissions Enquiry popup accessible anywhere on the site.

---

## 🛠️ Technology Stack

- **Framework**: React 19 + TypeScript
- **Bundler**: Vite
- **Styling**: Tailwind CSS v4
- **Icons**: Lucide React + Inline SVG Icons
- **Routing**: React Router DOM v7

## 🚀 Local Setup & Development

```bash
# Clone the repository
git clone https://github.com/derikaustin1-ship-it/Greenfield.git

# Navigate into the project
cd Greenfield

# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```
